이제 Supabase에 `bookmark_items` 테이블을 생성해줘.

이 테이블은 서비스에서 미리 제공하는 북마크 항목을 저장한다.
사용자가 직접 생성하는 데이터가 아니다.

컬럼:

- id
- url
- title
- description
- thumbnail_url
- created_at

설정:

- id: 자동 증가하는 정수형 Primary Key
- url: 필수
- title: 필수
- description: 선택
- thumbnail_url: 선택
- created_at: 필수, 기본값은 현재 시간

현재는 개발 단계이므로 RLS는 꺼줘.

테이블 생성이 끝나면 실제로 생성된 컬럼과 설정을 확인해서 알려줘.
