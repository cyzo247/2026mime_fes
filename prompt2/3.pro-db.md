이제 Supabase에 `folders` 테이블을 생성해줘.

이 테이블은 각 사용자가 자신의 북마크를 분류하기 위해 만드는 폴더를 저장한다.

컬럼:

- id
- user_id
- name
- created_at

설정:

- id: 자동 증가하는 정수형 Primary Key
- user_id: 필수
- name: 필수
- created_at: 필수, 기본값은 현재 시간
- user_id는 Supabase Auth의 사용자를 식별하는 값으로 사용한다.

현재는 개발 단계이므로 RLS는 꺼줘.

아직 다른 테이블과의 Foreign Key 관계는 설정하지 말고,
우선 folders 테이블 자체만 생성해줘.

생성 후 결과를 요약해서 알려줘.
