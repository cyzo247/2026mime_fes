이제 Supabase에 `user_bookmarks` 테이블을 생성해줘.

이 테이블은 사용자가 서비스에서 제공하는 `bookmark_items` 중 하나를
자신의 북마크 목록에 추가했다는 관계를 저장한다.

사용자가 북마크를 삭제하면 user_bookmarks의 해당 기록만 삭제하고,
원본인 bookmark_items의 데이터는 삭제하지 않는다.

컬럼:

- id
- user_id
- item_id
- folder_id
- created_at

설정:

- id: 자동 증가하는 정수형 Primary Key
- user_id: 필수
- item_id: 필수
- folder_id: 선택
- created_at: 필수, 기본값은 현재 시간

Foreign Key:

- user_bookmarks.item_id → bookmark_items.id
- user_bookmarks.folder_id → folders.id

user_id는 Supabase Auth의 사용자를 식별하는 값으로 사용한다.

또한 같은 사용자가 같은 bookmark_item을 여러 번 추가할 수 없도록
(user_id, item_id)에 UNIQUE 제약조건을 설정해줘.

현재는 개발 단계이므로 RLS는 꺼줘.

생성 후 컬럼, Foreign Key, UNIQUE 제약조건을 확인해서 알려줘.
